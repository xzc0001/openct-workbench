# 隐私与安全

## 仓库发布边界

只提交通用源码、空模板与合成测试生成代码。排除患者信息、实际影像及其
派生数据、机构名称、内部服务地址、凭据、CA/密钥、日志、数据库、权重与
引擎资源包。脱敏检查必须在提交和推送前完成，不能依赖上传后删除。

发布检查涵盖文件白名单、内容规则、暂存区与 Git 历史，并辅以独立秘密扫描
和本地标识核查。检查器不是数据匿名化工具，不能证明所有潜在信息均被识别。

## 实际运行

原始影像、体积、网格、HTML、截图、打印内容和日志都可能构成个人医学信息。
去掉姓名字段或使用随机任务号不等于匿名化。不得把实际检查作为公共演示。

使用 TLS、最小权限和限制网络访问；对账号库设置文件权限，备份与导出也需要
权限管理。访客链接是访问凭据，必须管理有效期和撤销。

## 报告问题

优先提供合成复现。公开 Issue、PR 与 Wiki 不得包含真实数据、内部地址或密钥。
若曾泄露凭据，应立即撤销或轮换，再按本地流程处理；仅删除后续版本不够。
