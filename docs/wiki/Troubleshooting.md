# 常见问题

| 现象 | 首先检查 |
| --- | --- |
| 服务提示缺少管理员 | 是否用 `auth.py` 初始化，服务是否读取同一个账户库 |
| 依赖或适配器不兼容 | 虚拟环境、固定版本、`pip check`，不要直接升级内部推理接口 |
| 缺失离线模型 | 权重根目录、任务目录层级及 checkpoint，模型授权是否适用 |
| CT 无有效序列 | 是否常规单帧 CT，层数、方向、间距、重复 UID 和定位片是否符合要求 |
| 只读用户看不到检查 | 是否由所有者或管理员给出检查级授权 |
| 访客链接无效 | 有效期、撤销状态、检查范围、当前来源及会话 Cookie |
| 传送不可用或被拒绝 | 本地固定目标、接收账户权限、对端是否忙碌及网络加密边界 |
| 容积不能显示 | WebGL2、浮点采样、纹理尺寸、内存，是否已回退表面 |
| 旧离线文件没有新功能 | 旧文件不会自动更新，需要重新导出 |
| 节点无法领取工作 | 调度开关、引擎/模型标识、预算、会话/证书和租约状态 |
| 内存不足 | CT 体积、所选结构和计算预算；保留输入后调整，不要修改原 CT |
| 打印布局不完整 | 浏览器打印缩放、A4 页面设置、视图数量与实际打印机预览 |

排查日志仅保存在受控环境。对外报告时只给出脱敏错误类型、版本与合成复现，
不要附完整临床日志、截图或内部 URL。
